# Typography — M3 Style Reference

> Use typography to make content readable and beautiful. M3's type scale includes 30 styles (15 baseline + 15 emphasized) organized by five roles.

Sources: [Overview](https://m3.material.io/styles/typography/overview) · [Type Scale Tokens](https://m3.material.io/styles/typography/type-scale-tokens) · [Applying Type](https://m3.material.io/styles/typography/applying-type) · [Fonts](https://m3.material.io/styles/typography/fonts) · [Editorial Treatments](https://m3.material.io/styles/typography/editorial-treatments)

## Overview

M3 typography organizes text into a single type scale with two style sets — **baseline** and **emphasized** — each containing 15 styles spanning Display Large down to Label Small. Emphasized styles (added in the M3 Expressive update, May 2025) carry heavier weight and are intended for bold, selected, or otherwise prominent text. Both sets are meant to be used together.

![Type at different scales.](https://lh3.googleusercontent.com/Ow6KY2aDdXx4z-a13GYltf1azIa1Z7_G14M0uTeS0FODRiM87ScDy0_7hf5FPWHi3K2FhNto9ddP94U7DQ6SxWXOODeYz2gmfdaiz1amwgc=s0)

![Type scale showing roles for "display", "headline," "title," "label," and "body."](https://lh3.googleusercontent.com/H7HQemhAdElVd6cCDlOyh0FhU3h8iD8kugnlLUFn1ScP8us3nqj1FslGURTVbbimZIHOCkIrjq5jOek3D3ixq8KMwNug0qPwL0lTzv_IgSFFjQ=s0)

Design tokens capture each style's properties — font, line height, size, tracking, weight, and variable font axes — enabling scalable, configurable typography across devices and contexts.

![Close crop of markdown text showing type scales referenced as "display-large" and "display-large-emphasized."](https://lh3.googleusercontent.com/FtpfhAnHzRkv9v64Ec7o6iT9LCg4Jz4rj6beaUd0tsyefFzccM8XPfIk8KUC3sKxmzAo86-JF6bqX9KbIDd9hKgLJssWwzkR_qv84q6XKLtGww=s0)

Five type roles define purpose:

- **Display** — largest text, for short important text or numerals on large screens
- **Headline** — high-emphasis text on smaller screens
- **Title** — medium-emphasis, relatively short text
- **Body** — longer passages of readable text
- **Label** — small utilitarian text (buttons, captions, navigation)

![Different examples of Roboto scaled to their respective roles: display, headline, title, body, and label.](https://lh3.googleusercontent.com/1ln7XGlJMAaZg3R5bogSK2Zon8ogE5VFdjtWg8khP2lcT9mS6Vf7zocKBH0gFLcSYCeAPhxsTK0QibKMM8dJpFD7E13YaNMv-JrAO42Gt59I=s0)

## Applying Type

Each role has three sizes: **large**, **medium**, and **small**. Together the roles and sizes establish clear page hierarchy across devices.

### Display

Reserved for short, important text or numerals. Works best on large screens. Consider expressive fonts (handwritten, script). Set optical size when available.

## Typesetting

Vertical typesetting uses padding, bounding boxes, and baselines to ensure legibility at any size. Platform considerations and text resizing conventions should inform your approach.

### Padding & Bounding Boxes (Web / iOS)

In web UIs, line height equals the bounding box height. Text is vertically centered within the bounding box following CSS [half-leading](https://www.w3.org/TR/css-inline-3/#leading-trim) behavior. The vertical text position is determined by the combination of bounding box and font metrics, not set directly.

![Diagram of bounding box equaling line height.](https://lh3.googleusercontent.com/kVdAGQXhGi2W9YfH3N0ZX9KJkKnpc-bsjOAg3tWtYeHr8x--uTrk_Y49tvDT3rwtVE12G-je8FG3rd6DywqSfWXwBk2M7pAulya83Ml3wjGB1A=s0)

Padding is the space between UI elements — between an image and a bounding box, or between the inner edge of the bounding box and the text.

![Diagram of 20 dp padding above text.](https://lh3.googleusercontent.com/ofazdaoe9Y2mL4Oefj7g_L7-yaRVZecYmExPhqw0CMVWbzn18xGdzzxkXOak_FQ8oszI1XH-BUgAsd3eiDWomwVhGZlkdlB1sdcEtlV0Vtg=s0)

![Measurements of label text padding.](https://lh3.googleusercontent.com/c-Xd3srZz38eMpP89GGFUqL6ibDUlvLILbWmE3SyIadz3v6osx2jNpQzXuXwj30_jUHhPSkP5ALsu_hOJGi3k-JrXkk5WXglGiz0dILEruNp=s0)

Vertical alignment steps:

1. **Line height** — measure the bounding box height
2. **Centering** — ensure equal top/bottom padding within the bounding box via center alignment
3. **Spacing** — use bounding box height plus top/bottom padding for spacing calculations

![Diagram of using padding and bounding boxes to measure line height, alignment, and spacing.](https://lh3.googleusercontent.com/gR_zZUnknndcR-NJEotK-rshizgc54jUA7qzp0TDrYV1sNjprNeUNsoETn72KqcrWT61bX5nIXUDpVr035eFbh_KkJgB8uP1J-7ExXAZ6BS6=s0)

### Baseline Method (Android)

The baseline is the invisible line upon which text rests. On Android, specifying distances relative to the baseline enables accurate implementation. The baseline approach is also useful for platform-agnostic design communication.

![Diagram indicating the baseline of text.](https://lh3.googleusercontent.com/I5c-Uge53PpSAf_V5JUBMML3_1ouix0TL99xVBLgNv5BNuQrxb1UhPEvP2TzubpCPApEwSredZQ6hDxVhAe0luStrcv4LddwoThxLQUfyEU=s0)

![Diagram of the distances between overline and container edge, plus subhead, overline, and caption text.](https://lh3.googleusercontent.com/CgXx25YXSe1l2T7QqEmDtLD-9vptGuT9ONqs_Z_ymaTncdxWIBMIrPzO3Svt_DL2zooqVZLGPsfN4MvZtE79JI6iSEm51TC3bI3eejLy34A=s0)

Vertical alignment steps:

1. **Line height** — measure baseline-to-baseline distance between lines
2. **Centering** — specify center alignment as a reference instead of baseline distance
3. **Spacing** — use the distance from a reference point to the baseline

![Diagram of using distance to baseline to measure line height, alignment, and spacing.](https://lh3.googleusercontent.com/3yEErrAiImN-qxnPPc_ln0WeE416pEN7iHaRcQPlzMluvla5w0ZoK09oTGefSQrgIaj29bUZrFG1T0sVHpTdOWUxGge1g9wQZideSuhMrUoSHw=s0)

## Ensuring Readability

### Line Height

Line height is tied directly to type size. M3 tokens are optimized for their intended size and use.

- **Larger type** (title, headline, display): recommended line height ratio of **1.2x** the type size

![An example of larger type with a line height ratio of 1.2](https://lh3.googleusercontent.com/LFuKIi2aGlf72f_A3yvGE-ncHvn7nQ3yj7M7zHCEljgjxJaWDtMrgjuHKy557yVppBOtlIEVl2SVHTbr_8QaHGPqSLdk6ZTPFvcXuoxIFJfs=s0)

- **Smaller body copy** (body, label): recommended line height ratio around **1.5x** the type size. Too tight undermines text flow; too loose breaks cohesion.

![An example of body type with a line height ratio of 1.5.](https://lh3.googleusercontent.com/TFXkp4WANGrF2VJ6AbJuYKFWa7QOOTDp-uchUNK6nBhk9-Qp2gg2V96xdgH8U3yjYoJCVNa2ln1-em5gCbw2bqSZWL1Pf5w7Iawhzi5Cf8p3=s0)

### Tabular Numbers

Use tabular (monospaced) figures rather than proportional digits in tables or values that change often (clocks, counters). This keeps values optically aligned for easier scanning.

![Vertical view showing the spacing variation in proportional numbers versus monospacing of tabular numbers.](https://lh3.googleusercontent.com/BskG7G1_XEXDjk548Xw7DT4xxmlW8ePL0ZOQdihQTM6AsDSWbuh1FCaOKu_ZpCrhev8DeIHKo42vtcOG5zsrFOJ5aXdzxysJfoAfXNpQaFA=s0)

![Times displayed in tabular numbers.](https://lh3.googleusercontent.com/iHKpHXTPSACBPeqMQw5d7GXnBYWQAH9j4B-8UqXZXH37-TISFiAqYf-tgnbb1URd992HF0u8KH9ed0AdrRysgEbV6Dnk8dKCFtiUBH5npG0l=s0)

### Icons with Typography

Align Material Symbols with typography for visual cohesion. [Learn more about matching icons and text](https://m3.material.io/m3/pages/icons/applying-icons#f9db4adc-ca78-473f-85eb-a351b73c39ac)

## Accessibility

### Color & Contrast

Choose appropriate color contrast between text and background. Contrast is quantified as a contrast ratio.

![Contrast between two colors, quantified by a contrast ratio, supports visual accessibility.](https://lh3.googleusercontent.com/goFACyp-thAmu70hw0vYZBOFWv7OySfYv9HRNwXvZMIQ9P2WCiyHyfgsCJE35fGXFpwSskOWX_XLoWaA7uz97PuPZ1lh_jw9sH0eaRiFGtc2=s0)

M3 targets two contrast levels:

- **3:1** for large text
- **4.5:1** for small text

[Learn more about contrast ratios](https://m3.material.io/m3/pages/designing/color-contrast#b248ecd2-9abd-4877-8f5e-ebfbb87e2048)

## Fonts

### Default Typefaces

**Roboto** — The default typeface for Android and the M3 typescale. Includes 3,300+ glyphs supporting hundreds of languages.

![A type specimen of Roboto.](https://lh3.googleusercontent.com/EkQ4Y0uqlLElvat_6ww9vzPrWILAT3Vmp3N5K4fsgMwOoxdBEmscWHqdqigR2wP6paFXmpLmPryht8MUzVfvYsKv4uAd7_uGZOG_TnBKnUY=s0)

**Roboto Flex** — A variable font extending Roboto with a continuous range of weights, widths, and additional customizable axes (including size-specific designs). 900+ glyphs with Latin, Greek, and Cyrillic support. Not yet part of the M3 typescale.

![A type specimen of Roboto Flex.](https://lh3.googleusercontent.com/2aZeUHyOXe0yaUcZk4yCg774-k1UiVi02FyOfoVMwRc1hJTsOhERLuU7fzXgJsTmmT6Hkv8Ds-c_c-T3pS1LwR1EZ_72IuKHTINCta9jux8yww=s0)

**Roboto Serif** — A variable serif family designed for comfortable reading. Extensive weights and widths across a broad range of sizes; functional enough for app interfaces.

![A type specimen of Roboto Serif.](https://lh3.googleusercontent.com/X-iJXo_zFMwPCclGNPUUQqHm-184vE84Tavs2SsYupdFJJBIAP0O5Bg5lyCtlVAFBlWuyLLUtylgWg7PaPfDnG9q1ScWji7GqYu0-OsOSkyw=s0)

**Roboto Mono** — Monospaced version of Roboto where each letter occupies equal space. Useful for code and keeping numbers aligned vertically.

![A type specimen of Roboto Mono.](https://lh3.googleusercontent.com/LMaircDfjO77VgbiKJNAz8UcxIc3kRufjePle2i7oLH9_kbvgEGcxU8IjCuv73lMDsSubbBX6YIz5VwFKDMwVmnFMDR7IJjROyxshjuvS-o=s0)

**Noto Sans** — A global font collection supporting 150+ scripts and thousands of languages. Each Noto Sans family is compatible with Roboto and serves as a "fallback" font for unsupported languages.

![A type specimen of several Noto Sans fonts.](https://lh3.googleusercontent.com/pfAhMuBM9hfiSa6uPDzCRHCivlqUZ6jZufCyaijjSuTHmKxJwz-x5YthTtaa9bJWQCPgLrFzlDRtf4rVtbr1d_CvvZ05ULtnMuTvDlogxv8=s0)

### Fallback Protection

Products using Roboto Flex should apply font fallback in order:

1. Roboto Flex
2. Roboto
3. Noto Sans font collection

This ensures consistent visual style regardless of character support.

![Text examples from Roboto Flex, Roboto, and Noto Sans all show similar styling.](https://lh3.googleusercontent.com/YAKWH5m4gHCZZlFNYswkO0AkAzGy39AcNVu1zG3poVn-n0jXXQy7nKpgT-w_ftH9tYe9ezdfEoanZrlhRsCDlgujAbHLrZuk-3wJD3i0K5Y3qA=s0)

### Emphasized Type Style Tokens

Emphasized styles share the same size, line height, and tracking as their baseline counterparts but use heavier weights. The primary difference: baseline styles use **weight-regular** (400) or **weight-medium** (500), while emphasized styles step up to **weight-medium** (500) or **weight-bold** (700), with `wght` axis values of 500 or 600 respectively.

To use an emphasized style, swap the baseline token for its emphasized counterpart:

- Baseline: `md.sys.typescale.display-large`
- Emphasized: `md.sys.typescale.emphasized.display-large`

### Where Emphasized Styles Can Be Used

#### In Components

Emphasized styles communicate hierarchy or importance — active/selected components, unread messages. They work well with:

- Badges
- Buttons (primary actions)
- Extended FAB
- Selected list items
- Selected menu items

Material components do not use emphasized styles by default. Swap the baseline token for the emphasized token of the same style to enable them.

#### By Weight

Apply emphasized styles to text that already uses weight (medium, bold) to reinforce hierarchy.

#### By Context

Apply emphasized styles to draw attention to specific component aspects — selected states, unread messages, key interactions. Weight and context emphasis can be combined.

![Diagram showing emphasized styles being applied in a UI of an active call with live translation turned on.](https://lh3.googleusercontent.com/BgMRvZc8eDdo9v86kNxhCNOiSw1Wv7fkVbYTLq_bY9QZXLfKuC-AaQn9_JmKDhbOBqdxmYoznv1ZlBhyigk8PYfuwAsrtaBtp7YqDQadYcs=s0)

1. **Weight:** Apply emphasized styles to already-bolded text for an expressive style
2. **Context:** Apply emphasized styles selectively to communicate hierarchy or state

## Customizing the Typeface

The M3 type scale uses two typeface references at different sizes:

- **Brand** — for larger styles (Headline, Display), focused on expression
- **Plain** — for smaller styles (Body, Label), focused on readability
- Roboto is the default for both

### Brand & Plain Typeface Tokens

**Brand**

| Name           | Token                   | Value  |
| -------------- | ----------------------- | ------ |
| Brand typeface | `md.ref.typeface.brand` | Roboto |

**Plain**

| Name           | Token                   | Value  |
| -------------- | ----------------------- | ------ |
| Plain typeface | `md.ref.typeface.plain` | Roboto |

**Weight**

| Name           | Token                            | Value |
| -------------- | -------------------------------- | ----- |
| Regular weight | `md.ref.typeface.weight-regular` | 400   |
| Medium weight  | `md.ref.typeface.weight-medium`  | 500   |
| Bold weight    | `md.ref.typeface.weight-bold`    | 700   |

### Customizing Type Styles

To customize existing type styles:

1. Change the **brand** and **plain** typeface tokens if using a different typeface
2. Adjust line height and letter spacing to refine appearance. Avoid changing type size — this can affect component rendering and reflow
3. Repeat for both baseline and emphasized styles. Keep emphasized styles visually consistent (e.g. all wider than baseline)

Heavier fonts may need wider letter spacing; fonts with long ascenders/descenders require different line heights. Variable font axes can be further adjusted.

**Note:** Customizing the M3 type scale or individual styles may prevent you from receiving typography token updates from Material.

### Font Size Units

| Platform         | Android | Web    |
| ---------------- | ------- | ------ |
| Font size unit   | sp      | rem    |
| Conversion ratio | 1.0     | 0.0625 |

Web browsers calculate REM based on the root element size. The default for modern browsers is 16px, so conversion is `SP_SIZE / 16 = rem`.

#### Example Conversions

| Android | Web      |
| ------- | -------- |
| 10sp    | 0.625rem |
| 12sp    | 0.75rem  |
| 24sp    | 1.5rem   |
| 60sp    | 3.75rem  |

### Letter Spacing Units

| Platform            | Android                                                   | Web                                                       |
| ------------------- | --------------------------------------------------------- | --------------------------------------------------------- |
| Letter spacing unit | em                                                        | rem                                                       |
| Conversion ratio    | (Tracking value in px / font size in sp) = letter spacing | (Tracking value in px / font size in sp) = letter spacing |

#### Letter Spacing Examples

| Android                                    | Web                                         |
| ------------------------------------------ | ------------------------------------------- |
| (.2 tracking / 16sp font size) = 0.0125 em | (.2 tracking / 16px font size) = 0.0125 rem |

## Editorial Treatments

Editorial treatments are standalone showcase moments driven by type — dynamic, attention-grabbing uses of custom sizes involving larger display type or bolder layouts. They depart from purely functional layouts and are meant for hero moments.

In the expressive system, editorial treatments can combine with motion, shape, or color for product-wide hero moments.

![A series of editorial moments making dynamic use of type, including a calculator, lock screen, and temperature.](https://lh3.googleusercontent.com/ev53UZRK0CWfnDhs22jim_yhZFnSolBEPg5IwuUJGgwWnqZA3iT58c-MAmi7YIOejurCjFd0EYTpAZ1POQsLbGMtdLiHE9gZMvp3csxwtt4T=s0)

### Use Cases

#### Celebrating Content

Dramatically take over the screen to mark a user action, memory, or preference. Match text style to the product's tone or a strong emotion — narrow/thin for serenity, bold/italic for liveliness.

![Large type reading "Mesa Verde National Park" with a hiker in the foreground.](https://lh3.googleusercontent.com/_f96Z-GV-cAbQmpKCj-Keg6s4rM6TfNLrZzkjpFVRS2wnACMbvScj90pXQqDVkQsrXv3HuwAPI2GoFFbLjYhfTlFp66pmIY7VFy7BBxvwglCCA=s0)

#### Voice of the User

Let users personalize typography appearance or adjust text based on input. Use customization selectively to frame mood and make it stand out.

![A text exchange in which one party is responding enthusiastically in extremely large letters.](https://lh3.googleusercontent.com/aIWtxiI3mObxA5vNa0tgNA8a89V2FRGKJIPDwOFDDjqkYNShmdmFAnqptxLK4bmFCFEPvZSZw9vJ2dWwT_R00KolfVj8le1Iu-yZexlmpimB9Q=s0)

#### Bespoke Functionality

Express moments of unique functionality within the product experience.

![A slider to adjust bedroom lights. The characters increase in width and weight as the brightness is increased.](https://lh3.googleusercontent.com/MOKMcp4KQUKuarOagUBezjsmfRUftgg4bZuIe7ss8B-RpdEBvAAintWivpRfcCCukxxgqDKpP3EoaJLD6HfOEg3KMQBlEK2n-NRxLLWcqFEmJQ=s0)

### Best Practices

- Ensure consistency between similar editorial moments — create tokens for each where needed
- Match the emotional tone of text to the task at hand
- Avoid mixing multiple or clashing styles in the same layout
- Don't mimic personalization theming

### Variable Axes for Editorial Treatments

Adjust variable font axes — weight, grade, width, optical size — to match font to feeling. Baseline and emphasized type styles can still be used. Editorial treatments should not be applied to labels or purely informational text.

#### Weight

Defines the overall stroke thickness. Variable fonts provide a continuous range of thicknesses. Common weights are regular and bold, but extremes from very light to very heavy are available.

![Many examples of Roboto Flex weights.](https://lh3.googleusercontent.com/_ZH0Kaelt3AZp6-KW-_8iAzJpqXcmjFDowWlVM8kdesekBF7fRPS7YoVYtNw7CBck4R4YUGb-tPiDMqwGJeK8qtEb9JscawmvErJ9mTZ09Q=s0)

![Light text in use as body text.](https://lh3.googleusercontent.com/c_gKfZUEwNoMuE_swIkrig6cXFWytTkRd1ZgI2m5mVSsJBiEc9TTlcy0CLJ8HlIEfj4ZfunjBfob6jM0h0oC9hny61MIjrECjNBRSbT2WBE0=s0)

> **Caution:** Very light weight for body text can be hard to read on lower-resolution displays, especially at small sizes. Consider lighter weights only at larger font sizes (display type).

> **Caution:** Excessive weight at smaller sizes makes text harder to read.

![Navigation bar using bold typography for label text.](https://lh3.googleusercontent.com/JxEboJh8oUw3JAa08wTj7Yl8CndLBoOChr9amAJTMlo2v6WBmFGEqQwYMI54QJPq3D0mNC9mpltggO0NWeOato8W2AUEH_x5_APOOUkGX4w=s0)

#### Grade

A secondary modifier of optical weight, independent of the weight axis. Both weight and grade affect stroke thickness, but grade adjustments are more granular and don't change letter widths or line breaks.

![Three ampersands set in Roboto Flex without grade over Roboto Flex with 150 grade.](https://lh3.googleusercontent.com/3HqXaLryPKUIj1IaC5Rfnzdcj2s1OVUJKRqjKUBPXN3TB9Q4x_1sCfQcEmsNsb0CI5OHaSGT-IugniC48bWebADFxLnygmoQp10QlzBHNPc=s0)

Roboto Flex offers a positive grade of 150 and a negative grade of 200.

When switching between dark and light mode, the same text may appear heavier. Consider using a negative grade to counteract this.

![A light and dark screen each showing the letter B.](https://lh3.googleusercontent.com/nNOT6dZnhO35p9L6JJOMBGxqzuugbja6Bm13PdwoVG5JRWeRH9SY7gs5R929Q4Mn97C6VxJ0ZzG8so1MbJ0dKH2iLgPJqCWkkQqNzvmlyUM=s0)

Grade can change emphasis without reflowing text — useful for states like selected filter chips.

![A list of amenities where selected filter chips have heavier grade.](https://lh3.googleusercontent.com/GPx4clVPV4vwGL6n3YNWAOYKhjSlFdl5OkrPdr5P-DM2-QVqrcHiU_DDT2OfiqaN3UsVXr_nDftRzvLDJZBAeb3UQCqy3jVaFDOSuXItueSN=s0)

#### Width

How much horizontal space characters occupy. Narrow width fits more characters per line; wider width offers more personality.

![The letter 'N' in Roboto Flex rendered in varying widths.](https://lh3.googleusercontent.com/fcsjvoTZQgt3S4tEgcJeKkFdxwB7j0kq4rPwSzLExgjzb5GXXaI46dDHnYhSnpdXubMSsV60bO7gd0FHWMHX1neKkRNqysx6pndBj6cYfMSzYg=s0)

Roboto Flex offers widths from 25 to 150.

#### Optical Size

Versions of a typeface optimized for different display sizes. Small optical sizes enhance readability; large optical sizes showcase letter form intricacies and offer more weights/widths.

![The word hello at a small optical size overlaid over the word hello at a large optical size.](https://lh3.googleusercontent.com/q145wn11t-bnGKRS9FqXq2XgXL2_zm_vcdzXtRMQj6lhcDjnhss8l3-z4BdWwmrhezO-Nuy-Kyioo2GNnuAhDS0PE8v96c3rxursoJNbhyEK=s0)

The typeface Literata has a continuous range of optical size, from 7pt to 72pt.
