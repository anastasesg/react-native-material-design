## Material Symbol Styles

Material Symbols are the current default icon set, replacing legacy Material Icons. They support three styles and four variable font axes. Legacy Material Icons remain available but lack variable font capabilities.

### Outlined

Outlined symbols use stroke and fill attributes for a light, clean appearance suited to dense UIs. Stroke weight can be adjusted to complement or contrast your typography.

![Examples of outlined symbols with stroke and fill attributes.](https://lh3.googleusercontent.com/NITdaioIfPMFXtgGSZOAUaQAmu5RnuM7lBu-tgnUlYJcGcYFkRHZW-PUvlKL9V2D8q1yDaTuPkKtE7sskQe38VnAuePzsG4dVBPdgMRIUsGZrQ=s0)

![Outlined icon set on grid.](https://lh3.googleusercontent.com/0j-lncgOKEaj1vIlqpCtJFYSABk8qd_ObLGjIHo6GoeiOMec3zhywlTCRoQKg7atKSw7pMKHKs5I3ONX_zksNw6t7y9O0edYzgH_sUFy7Qw=s0)

2dp outlined icons remain readable across sizes and applications.

![Four filled symbols showing full body human and proprietary icons.](https://lh3.googleusercontent.com/SfVfEC_iB2KCOovf_1uXq63G6rqF6O0mscTKJxS1r7pyyEzBd3wiCDM9uIthivq8HVworv5tHcviS1P2TnJhRvFecaevNjj-ii8JCOQEkCzQ=s0)

Some symbols should remain filled for optimal legibility — full-body human icons, proprietary icons, etc.

![Thin-lined outlined symbols correspond to app typography.](https://lh3.googleusercontent.com/LI8XSyc-00JXHDVzvPlpUW3hlUa1AOAw8WtDJEY8hFrT9HWaXcnLwLtp6xOtpAZKPfQ0LKw2xMwPTN49rCDbCNfOuj9nhV1Nst9rN7nLziqgJQ=s0)

Lighter stroke weights can mirror thin typographic lines for visual harmony.

### Rounded and Sharp

**Rounded** symbols use a corner radius that pairs well with heavier typography, curved logos, or circular design elements.

**Sharp** symbols use straight-edged corners for a crisp style that stays legible at small scales. Their rectangular forms suit brands not well-reflected by rounded shapes.

## Customizing Symbols — Variable Font Axes

Each Material Symbol has four adjustable axes: **weight**, **fill**, **grade**, and **optical size**.

### Weight

Defines the symbol's stroke weight. Range: **100** (thin) to **700** (bold). Weight also affects overall symbol size.

![400 regular-weight icons used in standard navigation drawer and modal navigation drawer.](https://lh3.googleusercontent.com/wKUXMKTdyZtth9GUf_fGzbdjTMjM_ZeEC1BhklAoF58Kwrfxe4VRG8S9QPgbM2_c5TyFCYM-u8uS8ixp3aTZqaagy9GFYcAY-I2UwwXfTA=s0)

### Fill

Transitions symbols between outlined (0) and filled (1) styles. Use fill to convey state transitions such as selected/unselected. Along with weight, fill is a primary attribute affecting overall symbol appearance.

### Grade

Provides more granular thickness adjustments than weight, with a smaller impact on overall symbol size. Grade can be matched between text fonts and symbols for visual harmony (e.g., text at -25 grade pairs with symbols at -25 grade).

![Symbol thickness at grade 0 and at negative grade.](https://lh3.googleusercontent.com/6deVhGCNQVFlz3vGsH5-kQL5T6CCPVRlPAhCuttePnTOlAwggnzBRbgoFY7Webri3bjr9a3tUbks9ywkVL2Fzh0LODF68YFsUda2jxYY-jpj=s0)

1. Grade 0 — thickness unchanged
2. Negative grade — thickness appears lighter

**Visual bleed compensation:** Dark icons on light backgrounds appear larger than light icons on dark backgrounds. To match apparent size:

- Light background (dark icon): grade **0** (default)
- Dark background (light icon): grade **-25**

### Optical Size

Range: **20dp** to **48dp**. Automatically adjusts stroke weight as icons scale, so proportions remain visually consistent across sizes — unlike traditional vector scaling which makes enlarged icons appear too heavy.

![Four icons gradually increasing in optical size.](https://lh3.googleusercontent.com/je6qof_lyVWK8xpAgUPfCky20Ut7WfMnqfiHLXYhcrOwXg82WSL-WJal-a9vdqukOy69W9HeIzwqU4uT1cLbFMNqYI8wTa2qfcdBHigWCSeI=s0)

Four optical sizes: 20dp, 24dp, 40dp, 48dp.

![Desktop dropdown menu with icon in active state.](https://firebasestorage.googleapis.com/v0/b/design-spec/o/projects%2Fgoogle-material-3%2Fimages%2Fmlhj7jch-18.png?alt=media&token=d577305e-e1f3-4621-a1a1-0f2151a6fded=s0)

Use 20dp optical size for dense desktop layouts.

![Forward and reverse symbols highlighted on device.](https://firebasestorage.googleapis.com/v0/b/design-spec/o/projects%2Fgoogle-material-3%2Fimages%2Fmlhj7te6-19.png?alt=media&token=57bd2017-700e-4caf-bd57-187905e3b0ae=s0)

Use 40dp–48dp symbols when primary actions need emphasis.

## Accessibility

### Labels

Label text provides short, meaningful descriptions for abstract symbols, particularly useful in navigation.

![Navigation bar showing four destinations, with 1 active destination featuring both icon and text label.](https://lh3.googleusercontent.com/j8oZj62CVfprVgWWH3n3mlJeRVzQmRC5CKr2cWHfoSX57ew8-pGjFAq-02JUcbvFbF_q8pk-t6uIsch5W3g7Mx4_vAjdRvxGYyqMwbnGRJg=s0)

![Navigation bar with four destinations with only icons, no labels.](https://lh3.googleusercontent.com/7OMGLPJL7_MNKLFjI-6WDtTNl71E6_33nW5veT5d11JTc12KcLittcZRo4UocqaFOVngK7aAwUQiaPbUblpgpGR84IuOKg7FAVsIMPc1rDe_=s0)

Icon-only navigation requires caution — icon meaning must be unambiguous and accessible. Labels can be omitted only when reduced visual impact is necessary.

### Small Icons

Material Symbols scale without fidelity loss. Simple symbols (e.g., star ratings) work at any size. Below 20dp, add accompanying text labels for:

- **Complex icons** — highly detailed or multi-part symbols
- **Key action icons** — essential to product usage

| ----------- | ----------- | ----------------------------------------- |
| 24dp        | 48dp        | Default (touch)                           |

## Localization

Test iconography across age groups, cultures, and languages. Key guidelines:

- Use labels alongside abstract icons
- Navigation items must always have labels for clarity and accessibility
- Account for varying tech literacy — frequent internet users may interpret icons differently than infrequent users

![Comparison of three UIs showing add to cart, add to bag, and add to basket.](https://lh3.googleusercontent.com/Bd216SHyMia-hNHEYbG3QzmK0DTg0qx0YiDQlQg_qe78YzOC-ad4kP_4Eu4gzyEDTpSd-UtYyMa5sQ__2tpRYbFL4suTNVrY0Z0WSq3txAJW=s0)

Translate icons for local markets — different locales may prefer a cart, bag, or basket for checkout.

### Cultural Significance of Colors and Symbols

Color carries cultural meaning (white = purity in the West, mourning in some Eastern cultures). Symbols also vary — owls symbolize wisdom in many Western cultures but are viewed negatively in some Eastern ones. Be mindful that meanings shift across cultures.

![Comparison of UIs where red and green are warning colors.](https://lh3.googleusercontent.com/QZaCZSYut1aimPBGl7YFyeg1TaTYsDOorpW9snbYy9v8EP1NAxeOgNXTnriEP8re4A5GfVLNiAwtWxaxLXbw5AZqeU5lvw1HSHMwP9zsfg_g=s0)

Some locales use red as a warning color; others use green.

| Live area | 20dp x 20dp          |
| Padding   | 2dp around perimeter |

## Icon Metrics

### Anatomy

![Diagram of a calendar icon on a grid highlighting six different elements.](https://firebasestorage.googleapis.com/v0/b/design-spec/o/projects%2Fgoogle-material-3%2Fimages%2Fmlhird2l-27.png?alt=media&token=c1bdaf8d-d963-42ad-95d5-33b07c5b7fd3=s0)

1. **Corner** — where two edges meet
2. **Stroke terminal** — the end cap of an open stroke
3. **Counter stroke** — inner strokes within enclosed shapes
4. **Stroke** — the primary lines forming the icon
5. **Counter area** — enclosed negative space
6. **Bounding area** — the full icon boundary

### Corners

Default exterior corner radius: **2dp**. Style-specific behavior:

| Style    | Exterior Corners | Interior Corners     |
| -------- | ---------------- | -------------------- |
| Outlined | 2dp rounded      | Square (not rounded) |
| Rounded  | Rounded (both)   | Rounded (both)       |
| Sharp    | 0dp (straight)   | 0dp (straight)       |

For shapes 2dp wide or less, stroke corners should not be rounded.

![Credit card symbol placed on grid with 2dp rounded exterior corners highlighted.](https://firebasestorage.googleapis.com/v0/b/design-spec/o/projects%2Fgoogle-material-3%2Fimages%2Fmlhiwgza-28.png?alt=media&token=f8095345-1164-4158-a4b8-a488954399de=s0)

Exterior corners with 2dp corner radii.

![Credit card symbol placed on grid with 2dp linear interior corners highlighted.](https://firebasestorage.googleapis.com/v0/b/design-spec/o/projects%2Fgoogle-material-3%2Fimages%2Fmlhis0bd-29.png?alt=media&token=09785c23-d95d-44ff-bfc9-8a578597246a=s0)

Interior corners should not be rounded (outlined style).

![Document icon placed on grid with overly rounded corners highlighted.](https://firebasestorage.googleapis.com/v0/b/design-spec/o/projects%2Fgoogle-material-3%2Fimages%2Fmlhiswrw-30-caution.png?alt=media&token=8a81e237-d9a0-4bca-a394-cbbe5ba1e253=s0)

**Caution:** Overly rounded corners reduce legibility.

!['Add more' icon placed on grid with inconsistent rounded corners. ](https://firebasestorage.googleapis.com/v0/b/design-spec/o/projects%2Fgoogle-material-3%2Fimages%2Fmlhit41a-31-dont.png?alt=media&token=69509827-8e53-4807-ab42-4a3a27beb3ec=s0)

**Don't:** Don't use inconsistent corner radii.
