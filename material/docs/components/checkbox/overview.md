# Checkbox

Checkboxes let users select one or more items from a list, or turn an item on or off

- Use checkboxes (instead of [switches](/components/switch) or [radio buttons](/components/radio-button)) if multiple options can be selected from a [list](/components/lists)
- Label should be scannable
- Selected items are more prominent than unselected items
