# Components

Components are interactive building blocks for creating a user interface. They can be organized into categories based on their purpose: Action, containment, communication, navigation, selection, and text input.

## Buttons

- [Button groups](https://m3.material.io/components/button-groups) - Button groups organize buttons and add interactions between them
- [Buttons](https://m3.material.io/components/buttons) - Buttons prompt most actions in a UI
- [Extended FABs](https://m3.material.io/components/extended-fab) - Extended floating action buttons (extended FABs) help people take primary actions
- [FAB menu](https://m3.material.io/components/fab-menu) - The floating action button (FAB) menu opens from a FAB to display multiple related actions
- [Floating action buttons (FABs)](https://m3.material.io/components/floating-action-button) - Floating action buttons (FABs) help people take primary actions
- [Icon buttons](https://m3.material.io/components/icon-buttons) - Icon buttons help people take actions with a single tap
- [Segmented buttons](https://m3.material.io/components/segmented-buttons) - Segmented buttons help people select options, switch views, or sort elements
- [Split buttons](https://m3.material.io/components/split-button) - Split buttons open a menu to give people more options related to an action

## Date and time pickers

- [Date pickers](https://m3.material.io/components/date-pickers) - Date pickers let people select a date, or a range of dates
- [Time pickers](https://m3.material.io/components/time-pickers) - Time pickers help people select and set a specific time

## Loading and progress

- [Loading indicator](https://m3.material.io/components/loading-indicator) - Loading indicators show the progress of a process for a short wait time
- [Progress indicators](https://m3.material.io/components/progress-indicators) - Progress indicators show the status of a process in real time

## Navigation

- [Navigation bar](https://m3.material.io/components/navigation-bar) - Navigation bars let people switch between UI views on smaller devices
- [Navigation drawer](https://m3.material.io/components/navigation-drawer) - Navigation drawers let people switch between UI views on larger devices
- [Navigation rail](https://m3.material.io/components/navigation-rail) - Navigation rails let people switch between UI views on mid-sized devices

## Sheets

- [Bottom sheets](https://m3.material.io/components/bottom-sheets) - Bottom sheets show secondary content anchored to the bottom of the screen
- [Side sheets](https://m3.material.io/components/side-sheets) - Side sheets show secondary content anchored to the side of the screen

## All other components

- [App bars](https://m3.material.io/components/app-bars) - App bars are placed at the top of the screen to help people navigate through a product
- [Badges](https://m3.material.io/components/badges) - Badges show notifications, counts, or status information on navigation items and icons
- [Cards](https://m3.material.io/components/cards) - Cards display content and actions about a single subject
- [Carousel](https://m3.material.io/components/carousel) - Carousels show a collection of items that can be scrolled on and off the screen
- [Checkbox](https://m3.material.io/components/checkbox) - Checkboxes let users select one or more items from a list, or turn an item on or off
- [Chips](https://m3.material.io/components/chips) - Chips help people enter information, make selections, filter content, or trigger actions
- [Dialogs](https://m3.material.io/components/dialogs) - Dialogs provide important prompts in a user flow
- [Divider](https://m3.material.io/components/divider) - Dividers are thin lines that group content in lists or other containers
- [Lists](https://m3.material.io/components/lists) - Lists are continuous, vertical indexes of text and images
- [Menus](https://m3.material.io/components/menus) - Menus display a list of choices on a temporary surface
- [Radio button](https://m3.material.io/components/radio-button) - Radio buttons let people select one option from a set of options
- [Search](https://m3.material.io/components/search) - Search lets people enter a keyword or phrase to get relevant information
- [Sliders](https://m3.material.io/components/sliders) - Sliders allow users to make selections from a range of values
- [Snackbar](https://m3.material.io/components/snackbar) - Snackbars show short updates about app processes at the bottom of the screen
- [Switch](https://m3.material.io/components/switch) - Switches toggle the selection of an item on and off
- [Tabs](https://m3.material.io/components/tabs) - Tabs organize content across different screens and views
- [Text fields](https://m3.material.io/components/text-fields) - Text fields let users enter text into a UI
- [Toolbars](https://m3.material.io/components/toolbars) - Toolbars display frequently used actions relevant to the current page
- [Tooltips](https://m3.material.io/components/tooltips) - Tooltips display brief labels or messages
